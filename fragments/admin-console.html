Lab Pack — Export for Offline Laptops

Downloads STC-Lab.html — one self-contained file with all students and all tests. Copy it to each lab laptop (USB stick). Students double-click it and test fully offline, no Wi-Fi and no server needed. The pack contains no answer keys — MCQ marks are counted here, on the Admin PC, at import time.

Export a fresh pack whenever students or tests change, and replace the old file on the laptops.

Import Lab Submissions (from USB)

In the evening, each laptop's teacher clicks Export (Teacher) in the lab app and saves the JSON file to the USB stick. Select those files here (several at once) and import them. MCQs are auto-graded on import; teachers then grade theory and fill-in-the-blank answers on this Admin PC as usual.

Importing the same file twice is safe — submissions already in the system are counted as duplicates and skipped.
